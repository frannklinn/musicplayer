# musicplayer
Aesthetic terminal-based music player made in Python with LRC lyric sync and animated UI.

# 🎵 LÁBIA — Terminal Music Player

Um player de música estilizado para terminal inspirado em interfaces cyberpunk e visualizers retrô.

O projeto sincroniza letras `.lrc` em tempo real enquanto exibe:
- visualizador animado
- disco de vinil girando
- barra de progresso
- gradientes ANSI
- interface minimalista no terminal
